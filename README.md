# tictactoe-odin
# Made for The Odin Project

Link to page: https://ethan-hannum.github.io/tictactoe-odin/

A simple tic-tac-toe game made for practice using private variables, factory
functions and IIFE's. Getting most code put into an IIFE was a small challenge
but I can see the positive impacts it can have. My code looks much cleaner than
before and not letting user's modify variable and values through the console can
increase security.
